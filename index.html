Blink LED

เรียนรู้วิธีการทำให้ LED กะพริบอย่างต่อเนื่อง

LED

Light Emitting Diode (LED) เป็นองค์ประกอบอิเล็กทรอนิกส์ที่ปล่อยแสงเมื่อมีกระแสไฟฟ้าไหลผ่าน

✨ คุณสมบัติของ LED

แรงดันไฟฟ้า: 2V - 3.2V
กระแสไฟฟ้า: 15 - 20 mA
ขาสีแดง: สายบวก (+) Positive
ขาสีดำ: สายลบ (-) Negative
ความต้านทาน: 220Ω หรือ 330Ω

📍 ข้อเตือน

⚠️ LED มีขั้วบวก-ลบ ต่อกลับจะไม่ติด ต้องใช้ตัวต้านทาน 220-330Ω เสมอ เพื่อป้องกันการไหม้

🔌 การต่อวงจร

ขั้นตอนการต่อ:
1. ต่อข่าว GND จาก Arduino ไปยังขาสีดำของ LED
2. ต่อตัวต้านทาน 220Ω เข้ากับขาสีแดง
3. ต่อปลายตัวต้านทานไปยัง Pin 10 ของ Arduino

💻 โค้ดของโปรเจค

const int ledPin = 10; //the number of the LED pin

void setup() {
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT); //initialize the LED pin as an output
}

void loop() {
  digitalWrite(ledPin, HIGH); //turn LED on
  Serial.println("LED is ON");
  delay(1000);
  digitalWrite(ledPin, LOW);
  Serial.println("LED is OFF"); //turn LED off
  delay(1000);
}

⚙️ วิธีการทำงานของโปรแกรม

  1. อ่านค่า LDR: ใช้ analogRead() เพื่ออ่านค่าความเข้มแสง (0-1023)
  2. ตรวจสอบเงื่อนไข: ถ้าค่า ≤ 100 (มืด) → LED ON | ถ้า > 100 (สว่าง) → LED OFF
  3. แสดงผล: ส่งข้อมูลไปยัง Serial Monitor เพื่อดูค่าและสถานะ
  4. เรียกซ้ำ: wait 500ms แล้วทำซ้ำตั้งแต่ขั้นที่ 1

💡 เคล็ดลับและการแก้ไข

  • ✓ LED ไม่ติด? ตรวจสอบว่าต่อขั้ว + - ถูกต้องแล้วหรือไม่
  • ✓ ต้องการปรับความเร็ว: เปลี่ยนค่า delay() จากตัวเลขในหน่วยมิลลิวินาที
  • ✓ ต้องการให้ LED สว่างมากขึ้น: ใช้ PWM (Pulse Width Modulation) ด้วย analogWrite()
  • ✓ เปิดหลาย LED: เพิ่มตัวแปร ledPin หลายตัว และ digitalWrite หลายครั้ง

LDR เซนเซอร์แสง + LED อัตโนมัติ

อ่านค่าความเข้มแสงและควบคุม LED ให้ติดอัตโนมัติ

LDR

Light Dependent Resistor (LDR) หรือ Photoresistor เป็นตัวต้านทานที่มีค่าเปลี่ยนแปลงตามความเข้มของแสง เมื่อมีแสงมากจะต้านทานน้อย เมื่อมีแสงน้อยจะต้านทานมาก

✨ คุณสมบัติของ LDR

แรงดันไฟฟ้า: 5V DC
ค่าอ่าน (Analog): 0-1023
ความต้านทานที่แสง: 1-10 kΩ
ความต้านทานในที่มืด: 1 MΩ ขึ้นไป
พิกัดลักษณะกำลัง: 100 mW
ความต้านทานอ้างอิง: 10 kΩ

🔧 หลักการทำงาน

LDR ใช้ในการตรวจจับแสง โดยการอ่านค่าแรงดันไฟฟ้าผ่าน Analog Pin บน Arduino ค่าที่อ่านจะเป็น 0-1023 ขึ้นอยู่กับความเข้มของแสง เมื่อแสงมากค่าจะสูง เมื่อแสงน้อยค่าจะต่ำ เหมาะสำหรับสร้างระบบไฟอัตโนมัติ

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ LDR:
1️⃣ ต่อ 5V จาก Arduino ไปยังปลายด้านหนึ่งของ LDR
2️⃣ ต่อปลายอีกด้านของ LDR ไปยัง A0 (Analog Pin)
3️⃣ ต่อตัวต้านทาน 10kΩ ระหว่าง A0 กับ GND (วงจร voltage divider)
4️⃣ ต่อ GND จาก Arduino ไปยังขั้วลบ

📍 ขั้นตอนการต่อ LED:
1️⃣ ต่อ Pin 10 ไปยังตัวต้านทาน 220Ω
2️⃣ ต่อปลายตัวต้านทานไปยังขาสีแดงของ LED
3️⃣ ต่อขาสีดำของ LED ไปยัง GND

💻 โค้ดของโปรเจค (LDR + LED)

const int ledPin = 10; //LED pin
const int ldrPin = A0; //LDR pin

void setup() {
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT); //LED as output
  pinMode(ldrPin, INPUT); //LDR as input
}

void loop() {
  int ldrValue = analogRead(ldrPin); //read LDR value (0-1023)
  Serial.print("Light Value: ");
  Serial.println(ldrValue);

  if (ldrValue <= 100) {
    digitalWrite(ledPin, HIGH); //turn LED on (dark)
    Serial.println("LDR is DARK, LED is ON");
  }
  else {
    digitalWrite(ledPin, LOW); //turn LED off (bright)
    Serial.println("It's BRIGHT, LED is OFF");
  }

  delay(500);
}

💡 เคล็ดลับและการแก้ไข

  • ✓ ปรับความไว: เปลี่ยนค่า 100 เป็นค่าอื่น (เช่น 300, 500) ตามสภาพแสงจริง
  • ✓ ดูค่าจริง: เปิด Serial Monitor (Ctrl+Shift+M) เพื่อดูค่า LDR แบบเรียลไทม์
  • ✓ ใช้ Serial Plotter: เพื่อดูกราฟค่าแสงเป็นตัวเลขและทำให้ปรับง่ายขึ้น
  • ✓ ควบคุมระดับสว่าง: ใช้ analogWrite() แทน digitalWrite() เพื่อปรับความสว่าง (PWM)
  • ✓ โปรเจคขั้นสูง: เพิ่ม digitalWrite LED หลายดวง หรือควบคุมอุปกรณ์อื่น

Switch ปุ่มกดควบคุม LED

ใช้ปุ่มกดเพื่อควบคุมการเปิด-ปิด LED อย่างง่าย

Push Button Switch

Push Button Switch เป็นปุ่มกดที่ใช้สำหรับเปลี่ยนสถานะการไหลของกระแสไฟฟ้า เมื่อกดปุ่มจะปิดวงจร เมื่อปล่อยจะเปิดวงจร เหมาะสำหรับการควบคุมอุปกรณ์ต่างๆ

✨ คุณสมบัติของ Push Button Switch

แรงดันไฟฟ้า: 3.3V - 5V
กระแสไฟฟ้า: 50 mA
วัสดุ: พลาสติกและโลหะ
จำนวนขา: 4 ขา (2 ชุด common)
ความต้านทานอ้างอิง: 10 kΩ (Pull-up)
สถานะ: HIGH = ปุ่มกด, LOW = ปล่อย

🔧 หลักการทำงาน

Push Button Switch ใช้อ่านสถานะ Digital Pin โดยใช้ digitalRead() ซึ่งจะคืนค่า HIGH (1) หรือ LOW (0) ตามสถานะของปุ่ม เมื่อกดปุ่มค่าจะเป็น HIGH เมื่อปล่อยค่าจะเป็น LOW (ขึ้นอยู่กับการต่อวงจร Pull-up หรือ Pull-down)

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ Push Button:
1️⃣ ต่อ 5V จาก Arduino ไปยังขา 1 ของปุ่มกด
2️⃣ ต่อขา 2 ของปุ่มกดไปยัง Pin 2 (Digital Input)
3️⃣ ต่อตัวต้านทาน 10kΩ ระหว่าง Pin 2 กับ GND (Pull-down resistor)

📍 ขั้นตอนการต่อ LED:
1️⃣ ต่อ Pin 13 ไปยังตัวต้านทาน 220Ω
2️⃣ ต่อปลายตัวต้านทานไปยังขาสีแดงของ LED
3️⃣ ต่อขาสีดำของ LED ไปยัง GND

💻 โค้ดของโปรเจค (Switch + LED)

int buttonState = 0; //variable for reading the pushbutton status
int LedPin = 13; //LED pin
int buttonPin = 2; //button pin

void setup() {
  Serial.begin(9600);
  pinMode(buttonPin, INPUT); //initialize the button pin as an input
  pinMode(LedPin, OUTPUT); //initialize the LED pin as an output
}

void loop() {
  //read the state of the pushbutton value
  buttonState = digitalRead(buttonPin);
  //check if pushbutton is pressed. if it is, the buttonState is HIGH
  if (buttonState == HIGH) {
    //turn LED on
    digitalWrite(LedPin, HIGH);
    Serial.println("Button Pressed - LED ON");
  } else {
    //turn LED off
    digitalWrite(LedPin, LOW);
    Serial.println("Button Released - LED OFF");
  }
  delay(10);
}

⚙️ วิธีการทำงานของโปรแกรม

  1. อ่านค่าปุ่ม: ใช้ digitalRead() เพื่ออ่านสถานะของปุ่มกด (HIGH หรือ LOW)
  2. ตรวจสอบเงื่อนไข: ถ้า buttonState == HIGH (ปุ่มถูกกด) → LED ON | ถ้า LOW (ปล่อย) → LED OFF
  3. ควบคุม LED: ใช้ digitalWrite() เพื่อเปิด-ปิด LED
  4. แสดงผล: ส่งข้อมูลไปยัง Serial Monitor เพื่อดูสถานะ
  5. เรียกซ้ำ: รอ 10ms แล้วทำซ้ำตั้งแต่ขั้นที่ 1

💡 เคล็ดลับและการแก้ไข

  • ✓ ปุ่มไม่ตอบสนอง? ตรวจสอบการต่อวงจรและใช้ Serial Monitor เพื่อดูค่า
  • ✓ ปุ่มส่ายไป-มา (Bounce)? เพิ่ม debounce delay หรือใช้ library Bounce2
  • ✓ ทำให้เปิด-ปิดสลับกัน: ใช้ตัวแปร toggle เพื่อจำสถานะเก่า
  • ✓ เพิ่มปุ่มหลายตัว: กำหนด buttonPin หลายตัว และ if-else เพิ่มเติม
  • ✓ ควบคุมหลายอุปกรณ์: ใช้ digitalWrite() สำหรับหลายพอร์ต

PIR เซนเซอร์ตรวจจับการเคลื่อนไหว

ใช้เซนเซอร์ PIR เพื่อตรวจจับการเคลื่อนไหวและควบคุม LED

PIR Sensor

PIR (Passive Infrared Sensor) หรือเซนเซอร์อินฟราเรดพาสซีฟ เป็นเซนเซอร์ที่ใช้ตรวจจับการเคลื่อนไหวของวัตถุที่มีความร้อน (มนุษย์ สัตว์ เป็นต้น) โดยการรับรูแรงส่องสว่างอินฟราเรดที่เปล่งออกมา

✨ คุณสมบัติของ PIR Sensor

แรงดันไฟฟ้า: 5V DC
กระแสไฟฟ้า: 50 mA
ความไวสูงสุด: 7 เมตร
มุมตรวจจับ: 110 องศา
เวลาตัวจับ: ปรับได้ 5-300 วินาที
สถานะเอาต์พุต: HIGH = ตรวจพบการเคลื่อนไหว

🔧 หลักการทำงาน

PIR Sensor ทำงานโดยตรวจจับการเปลี่ยนแปลงของรังสีอินฟราเรด เมื่อมีการเคลื่อนไหวเซนเซอร์จะส่งสัญญาณ HIGH (5V) ไปยัง Arduino ช่วงเวลาที่ตั้งไว้ (5-300 วินาที) หากไม่มีการเคลื่อนไหวเซนเซอร์จะส่งสัญญาณ LOW เหมาะสำหรับสร้างระบบไฟประหยัด หรือระบบสิ่งแจ้งเตือน

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ PIR Sensor:
1️⃣ ต่อ 5V จาก Arduino ไปยังขา VCC ของ PIR Sensor
2️⃣ ต่อ GND จาก Arduino ไปยังขา GND ของ PIR Sensor
3️⃣ ต่อขา OUT ของ PIR Sensor ไปยัง Pin 13 (Digital Input)

📍 ขั้นตอนการต่อ LED:
1️⃣ ต่อ Pin 10 ไปยังตัวต้านทาน 220Ω
2️⃣ ต่อปลายตัวต้านทานไปยังขาสีแดงของ LED
3️⃣ ต่อขาสีดำของ LED ไปยัง GND

💻 โค้ดของโปรเจค (PIR + LED)

int pirPin = 13; //the pin connected to OUT of PIR
int ledPin = 10; //the pin connected to LED
int pirValue; //variable to store the value from PIR

void setup() {
  Serial.begin(9600); //open Serial Monitor
  pinMode(ledPin, OUTPUT);
  pinMode(pirPin, INPUT);
}

void loop() {
  pirValue = digitalRead(pirPin); //read value from PIR (HIGH/LOW)
  if (pirValue == HIGH) { //if motion detected
    digitalWrite(ledPin, HIGH); //turn LED on
    Serial.println("Motion detected!");
  } else {
    digitalWrite(ledPin, LOW); //turn LED off
    Serial.println("Motion ended.");
  }
  delay(1000); //slight delay
}

⚙️ วิธีการทำงานของโปรแกรม

  1. อ่านค่า PIR: ใช้ digitalRead() เพื่ออ่านสถานะของเซนเซอร์ (HIGH หรือ LOW)
  2. ตรวจสอบเงื่อนไข: ถ้า pirValue == HIGH (ตรวจพบการเคลื่อนไหว) → LED ON | ถ้า LOW (ไม่มีการเคลื่อนไหว) → LED OFF
  3. ควบคุม LED: ใช้ digitalWrite() เพื่อเปิด-ปิด LED
  4. แสดงผล: ส่งข้อมูลไปยัง Serial Monitor เพื่อดูข้อความและสถานะ
  5. เรียกซ้ำ: รอ 1 วินาที แล้วทำซ้ำตั้งแต่ขั้นที่ 1

💡 เคล็ดลับและการแก้ไข

  • ✓ ปรับความไว: หมุน potentiometer บนเซนเซอร์ (ป้ายกำกับ Sx) เพื่อปรับความไวตรวจจับ
  • ✓ ปรับเวลา: หมุน potentiometer (ป้ายกำกับ TIME) เพื่อปรับระยะเวลาที่ LED ติด (5-300 วินาที)
  • ✓ ดูค่าจริง: เปิด Serial Monitor เพื่อดูข้อความและตรวจสอบการทำงาน
  • ✓ เพิ่มการหน่วงเวลา: เปลี่ยน delay() เพื่อป้องกันการเปิด-ปิดบ่อย
  • ✓ ควบคุมหลายอุปกรณ์: เพิ่ม digitalWrite() สำหรับอุปกรณ์อื่น (พัดลม ลำโพง ฯลฯ)
  • ✓ ระบบประหยัดพลังงาน: เหมาะสำหรับโปรเจคผนังไฟอัตโนมัติ หรือระบบสิ่งแจ้งเตือน

Ultrasonic เซนเซอร์วัดระยะทาง

ใช้เซนเซอร์ Ultrasonic เพื่อวัดระยะทางและควบคุม LED

Ultrasonic Sensor

Ultrasonic Sensor หรือเซนเซอร์อัลตราโซนิก เป็นเซนเซอร์ที่ใช้วัดระยะทางของวัตถุโดยการส่งคลื่นเสียงที่มีความถี่สูงและรับคลื่นที่สะท้อนกลับมา จากนั้นคำนวณเวลาที่ใช้เพื่อหาระยะทาง

✨ คุณสมบัติของ Ultrasonic Sensor

แรงดันไฟฟ้า: 5V DC
กระแสไฟฟ้า: 15 mA
ช่วงการวัด: 2 ซม. - 4 เมตร
ความถี่เสียง: 40 kHz
มุมการวัด: ประมาณ 15 องศา
ความแม่นยำ: ±3 มม.

🔧 หลักการทำงาน

Ultrasonic Sensor ทำงานโดยการส่งคลื่นเสียงขึ้น 40 kHz ผ่านขา Trigger (Trig) แล้วรอให้คลื่นสะท้อนกลับมา ซึ่งจะได้รับผ่านขา Echo บน Arduino จะวัดเวลาที่ใช้ (duration) แล้วนำมาคำนวณระยะทาง โดยใช้สูตร: Distance = (duration × ความเร็วเสียง) ÷ 2 ซึ่งหารด้วย 2 เพราะคลื่นไปและกลับ

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ Ultrasonic Sensor:
1️⃣ ต่อ VCC ของเซนเซอร์ไปยัง 5V ของ Arduino
2️⃣ ต่อ GND ของเซนเซอร์ไปยัง GND ของ Arduino
3️⃣ ต่อ TRIG (Trigger) ของเซนเซอร์ไปยัง Pin 2 ของ Arduino
4️⃣ ต่อ ECHO ของเซนเซอร์ไปยัง Pin 3 ของ Arduino

📍 ขั้นตอนการต่อ LED:
1️⃣ ต่อ Pin 10 ไปยังตัวต้านทาน 220Ω
2️⃣ ต่อปลายตัวต้านทานไปยังขาสีแดงของ LED
3️⃣ ต่อขาสีดำของ LED ไปยัง GND

📐 การคำนวณระยะทาง

สูตรการคำนวณ:
• Distance (ระยะทาง) = (duration × 0.034) ÷ 2 ซม.
• Duration = เวลาที่คลื่นใช้ไปและกลับมา (microseconds)
• 0.034 = ความเร็วเสียงในอากาศ (340 m/s แปลงเป็น cm/microsecond)
• หารด้วย 2 เพราะคลื่นเดินทางไปยังวัตถุและกลับมา

💻 โค้ดของโปรเจค (Ultrasonic + LED)

const int trigPin = 2; //Trig pin
const int echoPin = 3; //Echo pin
const int ledPin = 10; //LED pin
long duration;
int distance;

void setup() {
  pinMode(echoPin, INPUT); //Echo pin as input
  pinMode(trigPin, OUTPUT); //Trig pin as output
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  //Clear Trig pin
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  //Send sound wave (10 microseconds)
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  //Read value from Echo pin
  duration = pulseIn(echoPin, HIGH);

  //Calculate distance
  distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  if(distance < 50){
    digitalWrite(ledPin, HIGH); //LED on if object near
  }
  else{
    digitalWrite(ledPin, LOW); //LED off
  }
  delay(100);
}

⚙️ วิธีการทำงานของโปรแกรม

  1. เคลียร์ Trig: ตั้ง trigPin เป็น LOW แล้วรอ 2 microseconds
  2. ส่งคลื่นเสียง: ตั้ง trigPin เป็น HIGH ในช่วง 10 microseconds แล้วตั้งเป็น LOW
  3. รับสัญญาณ Echo: ใช้ pulseIn() อ่านเวลาที่สัญญาณ Echo เป็น HIGH
  4. คำนวณระยะทาง: นำค่า duration คูณ 0.034 แล้วหารด้วย 2 เพื่อได้ระยะทาง (ซม.)
  5. ควบคุม LED: ถ้าระยะ < 50 ซม. → LED ON | ถ้า ≥ 50 ซม. → LED OFF
  6. แสดงผล: ส่งระยะทางไปยัง Serial Monitor เพื่อดูแบบเรียลไทม์

💡 เคล็ดลับและการแก้ไข

  • ✓ ปรับค่า Threshold: เปลี่ยนค่า 50 เป็นค่าอื่น (เช่น 30, 70) ตามที่ต้องการ
  • ✓ ดูค่าจริง: เปิด Serial Monitor เพื่อดูระยะทางแบบเรียลไทม์
  • ✓ ใช้ Serial Plotter: เพื่อดูกราฟระยะทางและปรับง่ายขึ้น
  • ✓ เซนเซอร์วัดผิด? ตรวจสอบการต่อ TRIG และ ECHO ให้ถูกต้อง
  • ✓ เพิ่มเสียง Buzzer: เพิ่มเสียงเตือนเมื่อวัตถุเข้ามาใกล้
  • ✓ โปรเจคขั้นสูง: วัดระยะหลายจุด หรือสร้างระบบหลีกเลี่ยงสิ่งกีดขวาง

Waterproof Temperature Sensor

ใช้เซนเซอร์วัดอุณหภูมิกันน้ำ (DS18B20) เพื่อวัดอุณหภูมิและแสดงผล

Waterproof Temperature Sensor

Waterproof Temperature Sensor เป็นเซนเซอร์วัดอุณหภูมิที่มีเอาต์พุตแบบดิจิทัล ทนทานต่อน้ำและส่วนแวดล้อม มีความแม่นยำสูง เหมาะสำหรับการวัดอุณหภูมิในสภาพแวดล้อมต่างๆ เช่น น้ำ ดินหรือสภาวะอื่น

✨ คุณสมบัติของ DS18B20

แรงดันไฟฟ้า: 3.0V - 5.5V
ช่วงการวัด: -55°C ถึง +125°C
ความแม่นยำ: ±0.5°C
จำนวนขา: 3 ขา (VCC, GND, DATA)
โปรโตคอล: 1-Wire (Single Wire)
ความต้านทานอ้างอิง: 4.7 kΩ (Pull-up)

🔧 หลักการทำงาน

DS18B20 ใช้โปรโตคอล 1-Wire ในการสื่อสารกับ Arduino ซึ่งหมายความว่าต้องใช้เพียงสายเดียวสำหรับการสื่อสาร (นอกเหนือจากสาย VCC และ GND) เซนเซอร์จะส่งค่าอุณหภูมิแบบดิจิทัลที่ Arduino สามารถอ่านและแปลงเป็นอุณหภูมิเป็นองศาเซลเซียสได้ ต้องติดตั้ง Library DallasTemperature ก่อนใช้งาน

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ DS18B20:
1️⃣ ต่อสาย VCC (สีแดง) ไปยัง 5V ของ Arduino
2️⃣ ต่อสาย GND (สีดำ) ไปยัง GND ของ Arduino
3️⃣ ต่อสาย DATA (สีเหลือง) ไปยัง Pin 2 ของ Arduino
4️⃣ ต่อตัวต้านทาน 4.7kΩ ระหว่างสาย DATA และ VCC (Pull-up resistor)

📚 ขั้นตอนติดตั้ง Library

ต้องติดตั้ง Library สองตัว ก่อนเขียนโค้ดสำหรับ DS18B20:

  1. OneWire Library - ใช้สำหรับสื่อสารด้วยโปรโตคอล 1-Wire
  2. DallasTemperature Library - ใช้สำหรับควบคุม DS18B20

ดาวน์โหลด Library จาก Google Drive: คลิกที่นี่เพื่อดาวน์โหลด

วิธีติดตั้ง:
1. ดาวน์โหลดไฟล์ .zip
2. เปิด Arduino IDE → Sketch → Include Library → Add .ZIP Library
3. เลือกไฟล์ OneWire.zip และ DallasTemperature.zip
4. คลิก Open เพื่อติดตั้ง

💻 โค้ดของโปรเจค (Temperature Sensor)

#include <OneWire.h>
#include <DallasTemperature.h>

const int ONE_WIRE_BUS = 2; //กำหนดขาที่จะเชื่อมต่อ Sensor
OneWire oneWire(ONE_WIRE_BUS);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  Serial.println("Dallas Temperature IC Control Library");
  sensors.begin();
}

void loop() {
  Serial.println("Requesting temperatures...");
  sensors.requestTemperatures(); //อ่านข้อมูลจาก library
  Serial.print("Temperature is: ");
  Serial.print(sensors.getTempCByIndex(0)); //แสดงค่า อุณหภูมิ
  Serial.println(" *C");
  delay(1000);
}

⚙️ วิธีการทำงานของโปรแกรม

  1. รวม Library: รวม OneWire.h และ DallasTemperature.h เพื่อใช้ฟังก์ชันต่างๆ
  2. กำหนดขา: กำหนดขา Pin 2 เป็นสาย DATA ที่จะเชื่อมต่อเซนเซอร์
  3. สร้าง Object: สร้าง OneWire object และ DallasTemperature object
  4. อ่านอุณหภูมิ: ใช้ requestTemperatures() เพื่อสั่งให้เซนเซอร์อ่านอุณหภูมิ
  5. แสดงผล: ใช้ getTempCByIndex(0) เพื่อดึงค่าอุณหภูมิและแสดงไปยัง Serial Monitor
  6. เรียกซ้ำ: รอ 1 วินาที แล้วทำซ้ำตั้งแต่ขั้นที่ 4

💡 เคล็ดลับและการแก้ไข

  • ✓ ตรวจสอบ Library: ให้แน่ใจว่าติดตั้ง OneWire และ DallasTemperature Library แล้ว
  • ✓ ดูค่าจริง: เปิด Serial Monitor (Ctrl+Shift+M) เพื่อดูค่าอุณหภูมิ
  • ✓ ตรวจสอบการต่อวงจร: ตรวจสอบให้แน่ใจว่าต่อ Pull-up resistor 4.7kΩ ระหว่าง DATA และ VCC
  • ✓ ปรับ Pin: เปลี่ยนค่า ONE_WIRE_BUS เป็น Pin ที่ต้องการ (เช่น 3, 4, 5 เป็นต้น)
  • ✓ ควบคุม LED: เพิ่ม digitalWrite() เพื่อปิด-เปิด LED ตามอุณหภูมิ
  • ✓ แสดงแบบ Fahrenheit: ใช้ getTempFByIndex(0) แทน getTempCByIndex(0)
  • ✓ โปรเจคขั้นสูง: เพิ่มการแจ้งเตือนเมื่ออุณหภูมิสูงกว่าหรือต่ำกว่าค่าที่กำหนด

Water Level Sensor

ใช้เซนเซอร์วัดระดับน้ำเพื่อตรวจจับและควบคุม LED

Water Level Sensor

Water Level Sensor เป็นเซนเซอร์ที่ใช้วัดระดับน้ำในภาชนะหรือ tank โดยใช้หลักการวัดการนำไฟฟ้า (conductivity) เซนเซอร์ประกอบด้วยหลายขา contact ที่มีความสูงต่างกัน เมื่อน้ำสัมผัสขาไหนก็จะทำให้ค่าแรงดันไฟฟ้าเปลี่ยนแปลง เหมาะสำหรับการตรวจจับระดับน้ำและควบคุมระบบอัตโนมัติ

✨ คุณสมบัติของ Water Level Sensor

แรงดันไฟฟ้า: 5V DC
ค่าอ่าน (Analog): 0-1023
จำนวนขา Sensor: 6-10 ขา (ตามระดับน้ำ)
ความสูง: ประมาณ 10 ซม.
ความต้านทาน: ขึ้นอยู่กับระดับน้ำ
สถานะเอาต์พุต: Analog (ต่างตามระดับน้ำ)

🔧 หลักการทำงาน

Water Level Sensor ทำงานโดยการอ่านค่าแรงดันไฟฟ้าผ่าน Analog Pin บน Arduino ค่าที่อ่านจะเป็น 0-1023 ขึ้นอยู่กับระดับน้ำในภาชนะ เมื่อน้ำสูงค่าจะสูง เมื่อน้ำต่ำค่าจะต่ำ เหมาะสำหรับสร้างระบบสิ่งแจ้งเตือนระดับน้ำหรือระบบควบคุมการสูบน้ำอัตโนมัติ

🔌 การต่อวงจร

📍 ขั้นตอนการต่อ Water Level Sensor:
1️⃣ ต่อ Signal (S) ของเซนเซอร์ไปยัง A0 (Analog Pin) ของ Arduino
2️⃣ ต่อ VCC ของเซนเซอร์ไปยัง 5V ของ Arduino
3️⃣ ต่อ GND ของเซนเซอร์ไปยัง GND ของ Arduino

📍 ขั้นตอนการต่อ LED:
1️⃣ ต่อ Pin 6 ไปยังตัวต้านทาน 220Ω
2️⃣ ต่อปลายตัวต้านทานไปยังขาสีแดงของ LED
3️⃣ ต่อขาสีดำของ LED ไปยัง GND

📊 ความหมายของค่าเซนเซอร์

📈 การตีความค่า Analog (0-1023)

🔴 ค่า 0-200

Empty (ว่าง)
ไม่มีน้ำ หรือระดับน้ำต่ำมากที่สุด

🟠 ค่า 200-500

Low (ต่ำ)
ระดับน้ำต่ำ ยังไม่ถึง 1/4 ของภาชนะ

🔵 ค่า 500-750

Medium (ปานกลาง)
ระดับน้ำปานกลาง ประมาณ 1/2 ของภาชนะ

🟢 ค่า 750-1023

High/Full (สูง/เต็ม)
ระดับน้ำสูง หรือเต็มภาชนะแล้ว

⚠️ หมายเหตุสำคัญ
  • ค่าอาจแตกต่างกัน: ค่าที่แสดงอาจแตกต่างจากค่าที่บอกไว้ ขึ้นอยู่กับชนิดของเซนเซอร์และความบริสุทธิ์ของน้ำ
  • ควรทำการทดสอบโดย: ใช้ Serial Monitor ดูค่าจริงจากภาชนะของคุณ แล้วปรับค่า threshold ให้เหมาะสม
  • ทำความสะอาด: ทำความสะอาดเซนเซอร์เป็นระยะ เพื่อให้การอ่านค่าแม่นยำ

💻 โค้ดของโปรเจค (Water Level Sensor + LED)

const int ledPin = 6; //LED pin
int sensor = A0; //Water level sensor pin
int level = 0;

void setup() {
  pinMode(ledPin, OUTPUT); //LED as output
  Serial.begin(9600);
}

void loop() {
  level = analogRead(sensor); //read water level value (0-1023)
  Serial.println(level);

  if(level > 500){ //if water level is high
    digitalWrite(ledPin, HIGH); //turn LED on
    Serial.println("Water Level is HIGH - LED ON");
    delay(1000);
  }
  else{
    digitalWrite(ledPin, LOW); //turn LED off
    Serial.println("Water Level is LOW - LED OFF");
    delay(1000);
  }
}

⚙️ วิธีการทำงานของโปรแกรม

  1. อ่านค่า Water Level: ใช้ analogRead() เพื่ออ่านค่าระดับน้ำ (0-1023)
  2. เก็บค่า: เก็บค่าที่อ่านไว้ในตัวแปร level
  3. ตรวจสอบเงื่อนไข: ถ้า level > 500 (ระดับน้ำสูง) → LED ON | ถ้า ≤ 500 (ระดับน้ำต่ำ) → LED OFF
  4. ควบคุม LED: ใช้ digitalWrite() เพื่อเปิด-ปิด LED
  5. แสดงผล: ส่งค่าและข้อมูลสถานะไปยัง Serial Monitor เพื่อดูแบบเรียลไทม์
  6. เรียกซ้ำ: รอ 1 วินาที แล้วทำซ้ำตั้งแต่ขั้นที่ 1

💡 เคล็ดลับและการแก้ไข

  • ✓ ดูค่าจริง: เปิด Serial Monitor (Ctrl+Shift+M) เพื่อดูค่าระดับน้ำแบบเรียลไทม์
  • ✓ ใช้ Serial Plotter: เพื่อดูกราฟการเปลี่ยนแปลงระดับน้ำ
  • ✓ เซนเซอร์วัดผิด? ตรวจสอบให้แน่ใจว่าเซนเซอร์ไม่มีสนิม ลองเทน้ำบริสุทธิ์และลองใหม่
  • ✓ ระดับน้ำหลายขั้น: ใช้ if-else หลายชั้นเพื่อตรวจจับระดับต่าง ๆ (ต่ำ ปานกลาง สูง)
  • ✓ เพิ่มเสียง Buzzer: เพิ่มเสียงเตือนเมื่อระดับน้ำเกินหรือต่ำกว่าที่กำหนด
  • ✓ โปรเจคขั้นสูง: สร้างระบบควบคุมการสูบน้ำอัตโนมัติหรือระบบสิ่งแจ้งเตือน
  • ✓ บันทึกข้อมูล: บันทึกค่าระดับน้ำไปยัง SD Card เพื่อเก็บข้อมูล

Buzzer Sound

เรียนรู้วิธีการควบคุมเสียงสัญญาณแจ้งเตือนด้วย Buzzer

Buzzer

Buzzer เป็นอุปกรณ์ที่ใช้สำหรับสร้างเสียงในโปรเจค Arduino โดยในบทเรียนนี้เราจะเรียนรู้วิธีการส่งสัญญาณเพื่อให้เกิดเสียง

✨ คุณสมบัติของ Buzzer

แรงดันไฟฟ้า: 3.3V - 5V
ประเภท: Active / Passive
ขาสัญญาณ (+): สายสีแดง / ขายาว
ขากราวด์ (-): สายสีดำ / ขาสั้น

📍 ข้อเตือน

⚠️ Buzzer มีขั้วบวกและขั้วลบ หากต่อสลับขั้วจะไม่มีเสียงเกิดขึ้น และห้ามต่อตรงกับแหล่งจ่ายไฟที่แรงดันสูงเกินไป

🔌 การต่อวงจร

ขั้นตอนการต่อ:
1. ต่อขากราวด์ (-) ของ Buzzer เข้ากับช่อง GND ของ Arduino
2. ต่อขาสัญญาณ (+) ของ Buzzer เข้ากับ Pin 8 ของ Arduino

💻 โค้ดโปรแกรม (Tone)

void setup() {
  pinMode(8, OUTPUT); // ตั้งค่า Pin 8 เป็น Output
}

void loop() {
  tone(8, 1000); // ส่งเสียงความถี่ 1000Hz ที่ขา 8
  delay(500);
  noTone(8); // หยุดส่งเสียง
  delay(500);
}

⚙️ วิธีการทำงาน

  1. tone(pin, freq): เป็นฟังก์ชันสร้างเสียงตามความถี่ที่ระบุ
  2. noTone(pin): ใช้สำหรับหยุดการส่งสัญญาณเสียง
  3. การหน่วงเวลา: กำหนดความยาวของเสียงและช่วงจังหวะหยุด

DC Motor & L293D Control

เจาะลึกการควบคุมมอเตอร์กระแสตรงด้วย IC Driver มาตรฐาน

IC L293D Driver

L293D คือไอซีขับมอเตอร์แบบ H-Bridge ที่ออกแบบมาเพื่อควบคุมทิศทางและกระแสไฟฟ้า ช่วยป้องกันความเสียหายที่อาจเกิดขึ้นกับบอร์ดไมโครคอนโทรลเลอร์จากการดึงกระแสเกินของมอเตอร์

🔍 ข้อมูลทางเทคนิค

แรงดันการทำงาน: 4.5V - 36V DC
กระแสขับต่อเนื่อง: 600mA / ช่อง
กระแสขับสูงสุด: 1.2A (Peak)
ขาสัญญาณ: รองรับ PWM (Speed Control)
อุณหภูมิใช้งาน: 0°C to 70°C

📋 Wiring Connection Table

L293D Pin Connect To Description
1 (Enable 1)Pin 10 (PWM)ความเร็วพัดลม
2 (Input 1)Pin 9คุมทิศทาง A
3 (Output 1)Motor Leg 1ไฟออกมอเตอร์
4, 5, 12, 13GNDกราวด์ร่วม

🔌 Full Circuit

💻 Arduino Source Code (Speed Control)

// กำหนดขาสัญญาณ
const int enA = 10;
const int in1 = 9;

void setup() {
  pinMode(enA, OUTPUT);
  pinMode(in1, OUTPUT);
}

void loop() {
  // สั่งหมุนด้วยความเร็ว 75%
  digitalWrite(in1, HIGH);
  analogWrite(enA, 200);
}

Water Pump Control

การควบคุมปั๊มน้ำขนาดเล็กโดยใช้ IC Motor Driver L293D

Water Pump ทำงานร่วมกับ IC L293D

L293D เป็น IC ขับมอเตอร์แบบ H-Bridge ที่สามารถขับกระแสได้สูงสุด 600mA ต่อช่องสัญญาณ เหมาะสำหรับปั๊มน้ำขนาดเล็กที่ต้องการการควบคุมที่แม่นยำกว่าการใช้ Relay

✨ การต่อขา IC L293D

Pin 1 (Enable 1): ต่อ 5V (หรือขา PWM เพื่อปรับความเร็ว)
Pin 2 (Input 1): ต่อ Digital Pin 9
Pin 3,6 (Output): ต่อขั้วบวกของปั๊มน้ำ
Pin 4, 5, 12, 13 (GND): ต่อ Ground
Pin 8 (VCC2): ต่อไฟเลี้ยงมอเตอร์ (3-12V)
ขาลบปั๊มน้ำ: ต่อ Output 2 (หรือ GND หากหมุนทางเดียว)

🌟 ข้อดีของการใช้ L293D

ช่วยป้องกันสัญญาณรบกวนและกระแสย้อนกลับจากมอเตอร์ไม่ให้ไหลเข้าบอร์ด Arduino และสามารถสั่งเริ่มหรือหยุดมอเตอร์ได้อย่างนุ่มนวล

🔌 การต่อวงจร (L293D + Water Pump)

*ในแผนผังเป็นการเชื่อมต่อผ่านขา IN1 เพื่อควบคุมการทำงาน*

💻 โค้ดโปรแกรม

int IN1 = 9; // ต่อเข้าขา 2 ของ L293D

void setup() {
  pinMode(IN1, OUTPUT);
}

void loop() {
  digitalWrite(IN1, HIGH); // ปั๊มน้ำทำงาน
}
